## 证据边界

配置核验、连接成功与物理出口证据是不同结果。仅在目标、端口、自有内核 PID 与物理源地址可以明确关联时，才判断 TCP 出口是否符合配置。回环测试和关闭 TUN 的探测不能代替完整应用路径验收。

接口计数器包含所有程序和 LAN；UDP/DNS 需要抓包核对，不能以总流量、DNS 有回答或延迟探测成功替代出口证据。

## 待按实机环境完成的专项

- 真实主备拔插、自动恢复、DHCP/设备名称变化与休眠唤醒。
- 完整 TUN 应用路径下的默认直连兜底、运行中订阅及 provider 更新。
- UDP/DNS 实际物理出口、IPv6 双栈和仅 IPv4 场景。
- 独立服务卸载与完整管理员服务测试。

服务完整测试在受限环境中曾出现 Windows ACL/文件所有者操作拒绝访问（74 项通过、13 项失败、1 项忽略）。生产权限检查保持原有要求，需要在正常 Windows 权限环境复验。
